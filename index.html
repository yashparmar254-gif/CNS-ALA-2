SAFE EDUCATIONAL MODEL

🦠 Virus

A virus is a type of malicious software that commonly depends on a host file or program. When the host is executed, the malicious code may attempt to affect other files.

  • Usually associated with host files
  • Can modify or infect files
  • May spread through user actions
  • Can affect system availability

🪱 Worm

A worm is malware that can propagate from one system to another, commonly using network or software vulnerabilities.

  • Network-oriented propagation
  • Does not require traditional host-file attachment
  • Can spread rapidly
  • May consume network resources

🐴 Trojan

A Trojan disguises itself as legitimate or useful software and relies on a user being tricked into executing it.

  • Uses deception
  • May appear legitimate
  • Depends on user interaction
  • Can lead to unauthorized activity
